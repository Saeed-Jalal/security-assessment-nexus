## Security Assessment Agreement – Nexus OY

This repository contains my first professional **Security Assessment Agreement** created as part of a penetration testing project.

## Document Overview
**Title**: My First Security Assessment Agreement – Scope and Rules of Engagement  
**Client**: Nexus OY (E-commerce and Retail, Finland)  
**Assessment Focus:** Warehousing and Shipping IT Infrastructure  
**Date:** April 2025  
**Document Version:** 1.0

## Key Objectives
- Evaluate controls that protect admin access and sensitive databases
- Identify software/system vulnerabilities
- Simulate ransomware scenarios
- Test privilege escalation and access controls

## Scope
**In Scope:**
- Operations & Logistics Clusters
- SQL Inventory (development mirror)
- Warehouse admin systems
- Employee email (social engineering)

**Out of Scope:**
- Amazon Storefront and Support Clusters
- Production SQL server
- External DNS

## Rules of Engagement Highlights
- **Timeline:** 60 days
- **Methodology:** NIST SP 800-115 & OWASP
- **Techniques:** Black & Grey Box testing, vulnerability scanning, social engineering
- **Testing Window:** Limited to off-hours for certain types (e.g., DoS)
- **Restrictions:** No physical access, destructive tests, or production data exfiltration
- 
## Compliance and Authorization
- NDA-protected
- Internal-only data use
- Testing conducted with formal approval and documented escalation path
